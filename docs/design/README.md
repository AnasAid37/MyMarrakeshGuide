# Design references

The reference boards in this directory establish the approved visual direction for Sprint 1:

- warm-white editorial surfaces with generous spacing;
- terracotta as the primary action color;
- deep olive for navigation, trust and hospitality surfaces;
- desert gold for restrained premium accents;
- Playfair Display for editorial headings and Inter for product UI;
- arched architectural motifs inspired by Marrakesh without copying commercial photography into the application.

The application uses an original vector illustration and component tokens derived from this direction. Reference-board raster assets are documentation only and are not shipped in the web bundle.
